## Recovered behavior

An empty list returns false without queries or layout. Each node first tests its
live expiry word. Zero skips time calculation entirely. For a nonzero word, the
routine saves the accumulated clock, conditionally calls actual `69A430`, uses
unsigned `timeGetTime() >> 4`, then subtracts the late reread clock start with
dword wrapping. A stopped start (`FFFFFFFF`) skips the API.

The expiry word is reread after the API. The comparison is signed and strict:
only current-clock greater than expiry removes a node. Equality retains it.
This is not an unsigned deadline comparison or a host timestamp substitution.
A diagnostic API write changing the expiry to zero after the initial gate still
reaches the comparison; no second zero gate is invented.

Removal saves the next node before detaching, writes the actual replacement head,
marks the matching slot available with word value 1, and executes the shared
ordinary text/gadget/link destructor before continuing from that saved identity.
It neither restarts at a late head nor follows a rewritten freed-node link.
Foreign slot identities match none of the 14 slots; duplicate slot associations
retain the original immediate word stores rather than reference counting.

Only when at least one node was removed does the routine relayout from the live
list head. Live reserved19/1A bytes control the initial reserved-row offset; Y
and repeated line-step additions preserve signed dword wrapping. It returns true
even if a supplied release effect changes the head or no nodes remain to lay out.
No-removal updates preserve the existing Y words.

The shared helpers now explicitly traverse first then last in the inspected
`539110` and `538FA0` order, including the destructor's discarded replacement-head
traversal. This corrects an inspected read-order omission; all 450 earlier
insertion projections are retained by both rebuilt runners. The former original
expectations were reused with their immutable source/receipt identities.

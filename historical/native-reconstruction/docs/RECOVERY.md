## Facing recovery

YRpp supplied names/structure hypotheses, not a licensed code dependency or a
base-game address table. The actual base routines were located in the supplied
binary, disassembled locally, and exercised using its original instructions.

| Routine / field | Base RA2 VA |
| --- | --- |
| Facing constructor with ROT (inspected) | `0x4B8510` |
| SetDesired | `0x4B8550` |
| SetCurrent | `0x4B8630` |
| Current (hidden return pointer on stack) | `0x4B8700` |
| IsRotating | `0x4B87B0` |
| Clockwise predicate | `0x4B87E0` |
| Counterclockwise predicate | `0x4B8820` |
| SetROT | `0x4B89B0` |
| Timer remaining helper, used by SetCurrent | `0x453B30` |
| Global frame counter | `0xA2894C` |

Observed object fields: desired angle at +0, starting angle at +4 (each is a
16-bit value in a four-byte slot), timer start at +8, unused timer field at +12,
duration at +16, ROT angle at +20. The unused field/padding bytes are intentionally
not compared or modeled; the routines write stack-derived unused padding.

Recovered behavior implemented in `src/sim/Facing.hpp`:

- Angles wrap modulo 65,536. The difference is narrowed to a signed 16-bit value;
  exactly half a turn is `-32768`, including the signed tie behavior.
- ROT is capped at 127 above; the low byte is shifted by eight. Negative inputs
  retain the original low-byte behavior, although the loaded Rhino has ROT=5.
- Remaining ticks use signed 32-bit wrapped subtraction. Timer start -1 returns
  the stored duration; expiration returns zero. Rotation requires signed ROT > 0
  and nonzero remaining time.
- Steps are `abs(signed difference) / signed ROT`. During interpolation that
  quotient is narrowed to signed 16 bits, as in the executable.
- **Current = desired − (difference / steps) × remaining**, wrapping to 16 bits.
  Division happens BEFORE multiplication. Do not algebraically reorder this.
- A repeated desired angle does not restart the timer. A new desired angle begins
  from the current interpolated angle. A positive ROT starts the new timer with
  the truncated step count. Sub-step turns therefore snap to the new angle.
- SetCurrent only changes the two angles when the requested angle differs from
  the current result, but always resets the timer to zero duration.

Concrete discriminator: start 0, desired 8193, ROT 1280, six remaining ticks gives
current **3**, not 0. A multiply-before-divide implementation would lose this
base-game behavior. YRpp's inspected Current expression uses that other order;
we make no claim here about which original YR binary it matches.

## Numeric policy

Facing uses original 16-bit wrapped angles, signed differences, explicit signed
32-bit timer wrapping, and C++ signed integer division toward zero. The division
order is preserved from the base binary. Authoritative drive positions now use signed integer leptons (256 per cell).
Cell-space doubles are presentation/input conversions only. Track interpolation
retains original binary64 operations, a float32 store, truncation, and round-toward-
zero behavior, scoped to restore the host rounding mode. See MOVEMENT.md for the
x87 control-word evidence and the bounded domain compared on arm64. Direction
queues, plane-relative Z, direct routing, sampled clearance, display cadence, pause
and target lifetime remain adapters.
The skirmish host uses original coarse timer quanta with no catch-up accumulation;
destination bearings use prepared original lookup data, not standard atan2.
See TIMING_TARGETING.md and CURVES.md for oracle and platform-integration boundaries.

## Portability

CMake separates the headless libraries from SDL (`RA2_BUILD_SDL=OFF`). Public code
uses C++/SDL/library APIs; Apple paths are limited to optional convenience scripts
and documentation. Windows and Linux have not been built or tested. The current
Mac development executable dynamically links Homebrew SDL3, OpenSSL and LZO. It is
not a self-contained distributable bundle. Future packaging must include each
library's applicable notices and corresponding-source obligations.

The Outpost 2 checkout was read only for its architecture, build/recovery documents
and differential harness design. No files or processes there were changed.

## Preserved algorithm and ownership

40FF10 initializes index+10 to-1, +18/+1C/+20 to zero, and clears only flags+14's
low three bits. Preserve the initial auxiliary interface projections, late masked
byte load/store and subsequent base/derived interface transitions. Fields and
unused backing remain independent; this is typed portable C++, not an original
object layout or lifted runtime.

41EBE0 clears the image before associated/expired stores, projects derived
interfaces and queries the supplied associated Object Type. It stores Type+AC,
then reads **signed whole-SHP canvas dimensions at+2/+4**, not frame0 dimensions.
X/Y come from the constructor arguments. 41ED70 instead clears association,
rectangle, image and expired byte without a Type query. Both append to the first
physical registry83C648, then the generic registryAC0D60, then lazily initialize
the shared table. Existing nonzero initialized bytes bypass generation unchanged.

Each append tests signed live count against capacity. At capacity, a non-owned
nonempty allocation refuses growth; nonpositive increment also skips appending.
Otherwise it requests wrapped capacity+increment with argument0 and tests only
the result low byte. After that child it rereads count/backing, publishes count+1
before the slot store, and independently continues to the second registry even
when the first append was skipped. Resize failure is a skipped append, not a
failed constructor. Recovered control borrows real counts/spans/capacities/
ownership bytes/increments; it does not invent a heap growth implementation.

41F0F0 sets expired+3C to1 only for equal associated-pointer identity, including
null==null. The removed argument is ignored. 41F110 first lazily generates the
table when needed, saves count-minus1 once and traverses backward. Its backing is
retained between non-deleting visits and reloaded after each virtual deleting
child. It never replaces the saved reverse extent with live count. A null slot
would be dereferenced for its expired byte before the original's later null test;
the native nonfaulting profile refuses that input.

41F9C0 projects derived interfaces, searches/removes the first match in83C648,
then independently searches/removes the first match inAC0D60. It reuses the
existing first-only count-before-shift kernel, preserving live backing/count
rereads and unused tails. It then performs the base interface-only destructor
and frees only for deleting low bit1. Both deleting destructors return the same
record identity, including a supplied free request. 410340 performs only base
interface projection and the low-bit free, without derived registry removals.
The typed dispatch state preserves that distinction on retained-tail revisits.

Cases cover absent/duplicate/first/interior/last matches, empty and nonempty
registries, independent growth policies/failure, raw low-byte results0/1/256/257,
signed canvas extrema, raw flags, null association, ignored removed arguments,

## Readable algorithm

`TeamAdmission.hpp` borrows fields and exposes children as live services. It keeps
the existing-Team comparison before placement/health, the loading-sensitive flag76
test and exact current House match. A radio result uses only its low byte and
admits only the entered aircraft exception. Mission16C is called again after a
nonnull/-1 first result; the second result is forwarded unchanged to594DB0.
Byte379, TypeA9, current Script action8, kind2 and byte37A retain their original
short-circuit order. An existing Team can be displaced only when its signed
priority is lower. The last aircraft query forwards argument0 and tests the
returned first word before target254.

Only after those gates does the routine publish output0. Each scan saves its
index before Type84, then rereads the current Type/TaskForce after the child.
Each failed match publishes the next index. Final counts84 are compared as signed
32-bit values to the required count. Negative TaskForce count is not silently
clamped: it can reach slot0, as the original does. Native span checks refuse
entered invalid storage. The original dereferences Foot+4C4 before its null test;
the native interface refuses a null Foot rather than inventing a safe false result.

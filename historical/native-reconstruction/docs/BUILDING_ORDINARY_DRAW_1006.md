## Algorithm and stack ownership

The parent first saves the packed Cell from1A0, then gets image68. Null returns
before RTTI/Type/mission work. A kind6 actor with stage42C zero and Mission19 walks
18 live pointers at454 and stores each nonnull object's17D byte to1, in order,
including duplicates. Type1385 then gates the remaining drawing. The saved Type
11D4 adjustment survives later Type mutations.

Mission16 queries partner0 and its Type80/B44, then a separate Type80/B1A only
when needed. The resulting choice is saved across later children. Mission24
short-circuits timer predicates A90/AB0/B30. An entered timer branch multiplies
fraction496C70 by live137C under original53-bit/toward-zero FP, applies later
AB0/B50/B30 decisions, clamps signed frame, reloads image68 and chooses the
extra frame from live damage/Rules1368. It draws once, then returns. Equal and
unordered comparisons choose the damaged branch; no replacement FP model.

The ordinary branch optionally replaces image from11A0/11B0 and uses adjustment
-20 only if that image is nonnull. Missions18/19 retain offsets198/446; others add
live11E4/11E8. Foundation height0 then width form wrapped `(dimension<<8)-256`
inputs to actual6A2870. Global85029C is saved before a second width query, whose
signed result>=8 zeroes only that saved value.

Positive caller clip height enters the main body. Its initial signed SHP count/2
is retained across frame43BE20: a smaller result calls frame again; otherwise the
count is reread and divided again. There is no invented clamp on the second frame
result. Map/Cell height is sign extended, then live Type11FC is added, followed by
height1B8 and projection6A2970. The saved11D4 adjustment is reduced by that result.
Auxiliary11CC draws only with a nonzero stage, uses adjustment-1-projected height,
calls frame again and reloads11CC after that child. Mission16's overlay checks
saved alternative selection, damage/Rules and late image11A8/11B8, with adjustment
minus projected height. Missing overlays retain the original early returns.

All final6D1510 calls preserve15 arguments: image, frame, original point pointer,
original clip pointer,0,256,adjustment, followed by eight pending words. The first
three pending words are mode2 for main/timer or0 for auxiliary/overlay,1 and the
signed Cell-height sum. The last five are saved global,0,offsetX,offsetY,0 for the
main body and zeros otherwise. Cell548070 consumes only its packed-Cell pointer
(ret4); height1B8 consumes none. Final6D1510 consumes all15 (ret3C). Children may
mutate point/clip and later draws retain those exact identities and values.

CRT flag zero supplied.

Visibility divides signed Z by that separate divisor toward zero. If the quotient
is q, the shift is `q/2` toward zero plus one when q is odd. In particular, q=-1
produces shift +1 and q=-3 produces zero; mathematical ceiling would differ.
Signed X/Y division by 256 precedes word subtraction/truncation. Primary tests
Cell `+0x12C` bit 8; secondary tests `+0x140` bit 2. Clear means true. Odd q first
tests the selected Cell, then only on clear calls actual neighbor(3) and tests
that result. Neighbor reads the **selected Cell's stored coordinates**, adds as
words, and uses the actual combined signed-index lookup. Misses mutate the shared
fallback point, including twice on one predicate. Tests cover stored-coordinate
disagreement, aliases, signed boundaries, wrapping and upper flag bits.

Secondary returns false before division or lookup when all three are nonzero:
mode `0xA3D298`, current House byte `+0x13D`, and `0xA3D548`. Invalid native
division inputs are refused only when division is reached; even those inputs
are accepted by this shortcut. These are safety boundaries, not original fault
emulation. Flag names remain numeric; actual shroud/fog updates are not recovered.

Discovery compares the discoverer pointer with live current House. Repeated
current `+0x373` or other `+0x374` rejects. Other first writes `+0x374=1` before
Object's nonnull check, so a null discoverer can still leave that write. House
control returns raw byte `+0x134` in nonzero mode, normalized OR of `+0x134/135`
in mode zero. Nonhuman discovery obtains actual current-or-queued Mission; 14
queues 15 with the second argument zero. QueueMission preserves the current
19 and current28/request5 gates, -1 no-write and current/queued comparisons;
queued dword precedes cleared `+0xA4`. Nonzero second-argument virtual children
are excluded, not stubbed as verified behavior.

Current discovery writes actor `+0x373`, then owner `+0x5668/5669` with repeated
owner reads. If actor `+0x372` is zero, loading zero and a nonnull Tag invoke the
supplied event service with five exact arguments `(4, actor, context, 0, 0)`.
The owner is reread afterward before `+0x13C=1`. Diagnostic Tag cases replace the
owner to prove that late read; their event effects are supplied tests, not observed
gameplay. Other discovery repeats its `+0x374=1` assignment. Optional Tag execution
itself remains unrecovered. Trace/store callbacks are read-only observations;

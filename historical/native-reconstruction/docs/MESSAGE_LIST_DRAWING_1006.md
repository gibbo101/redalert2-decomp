4CF260 truncates force to its low byte once, before the loop. Each node draw
return is ignored, and the actual Next is queried after drawing, including a
refused draw. A callback that changes Next therefore changes traversal. The native
kernel borrows the existing nodes, calls the single recovered drawing kernel,
and reads node.next afterward. Optional tracing observes visited and saved Next
identities without supplying either answer. Destroyed owners and more than
1,048,576 visits explicitly refuse; original faults/nontermination are not claimed.

The ordinary5B5B30 path loads the head and dispatches head+2C with force1 if
nonnull. A nonzero editor byte explicitly refuses before drawing. The complete
original range is inspected, but the editor/window/mouse/IME/input branch is not
recovered or covered by this scope. Arbitrary non-text gadget classes are also
outside it. Do not label this complete general5B5B30 recovery.

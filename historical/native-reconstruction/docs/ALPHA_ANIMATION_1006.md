## Recovered behavior

41F950 always publishes initialized1 before filling the table, including when the
previous byte is already nonzero. For index`(source<<8)+old`, the generated value
is`min(255,((index&255)*(index>>8))/127)`. Original signed magic division simplifies
to this integer quotient over the complete nonnegative initializer domain. Drawing
reads the full destination word for indexing; it does not truncate it to a byte.
A lookup outside the actual64KiB table refuses in the native safe profile.

Both passes traverse forward with live count/backing. Rectangle drawing does not
check expired+3C. A missing cached image triggers associated Object virtual84,
then Type+AC is stored through the **saved physical slot**. Only afterward does
the caller reload the current global backing/slot/cache. Fixtures exercise count
growth/shrink, replacement backing and replacement saved-slot contents. Old slots
must remain alive through the synchronous child/store; the API documents this
lifetime requirement. Point drawing skips any nonzero expired byte and has **no
lazy Type query**. A missing point cache refuses rather than inventing a loader.
This corrects the earlier inspection hypothesis that both passes lazily resolved.

Record bounds are copied and translated by live Tactical origin and viewport.
The rectangle pass intersects record bounds first with a copy of the current
requested rectangle. The intersection gates drawing and supplies its left/top;
the subsequent frame crop uses the copied **requested right/bottom**, rather than
the intersection's right/bottom. It subtracts both viewport coordinates at alpha
addressing. The point pass intersects again against the caller's60x30 rectangle,
uses the final tile intersection extents, and subtracts viewportY only.

Both use frame0 raw bytes. The signed frame count is tested with unsigned JBE,
so only zero chooses default bounds; negative counts still enter frame0. Zero
count/default geometry and entered zero/negative spans retain their control flow.
Rows/columns store only when positive. The fast/wrapped test preserves its
original extra4-byte probe and single wraps after pixels and row gaps.

Point drawing additionally reads the tile mask. Byte0x20 skips a store. Mask
origin comes from the tile intersection **before frame cropping**; its row gap
uses the intersection width, even if the frame crops the pixel span further.
Wrapped drawing reloads the alpha owner after stores and retains the prior owner
on skipped mask pixels. Both backing bytes and numeric word spans are verified.
Malformed/faulting raw payloads, missing required children/slots, ambiguous
backing, oversized geometry/execution and out-of-table lookups refuse explicitly.
Compressed-image decoding and arbitrary malformed-input fault emulation are absent.

`RadarSurfacePixelsBinding`. Copying, mark stores and nonzero reads/writes resolve

which the caller must bind using `RadarActorsBinding` and the same actor world.

reference owners. Mark House index15F40 remains a separate pure borrowed field;
it is not radar alliance index30. Both branches use the same live scheme records,
including palette30C and index330. Palette/index access retains the actual late
ordering after stock C0/CC and resolver returns.

Construction makes no surface/actor/House/registry/gameplay queries. Supplied table
associations are validated before binding; zero and nonzero callbacks restore on
normal exit and faults. This binding is immovable, and borrowed owners/callback
contexts must outlive it. Faults propagate with original earlier effects retained;
no rollback, original malformed-pointer parity or general surface engine is claimed.
Native guards cover no-query construction, actual zero/nonzero dispatch, duplicate
tables, distinct registry-reference owners, normal restoration and fault unwinding.

The proof executes zero→nonzero and nonzero→zero without reconstructing records or
resetting pixels/bitmap/actors/schemes/floor cache between calls. The mode transition
